Coding agents on every machine,
in one Mac app.

agentZ runs Claude Agent, Codex, Gemini CLI, OpenCode and every other ACP agent side by side, across your projects, your Mac and your Linux servers, with real terminals next to them.

curl -fsSL https://ahrorbeksoft.github.io/agentZ/install.sh | sh

macOS: installs agentZ.app · Linux: installs agentz-server

Any ACP agent

Install agents from the ACP Registry, or add your own command. Log in the way each agent offers.

Threads across projects

Every conversation is a thread in the sidebar, with its project, branch and status.

Your other machines

Add a Mac or a Linux server over SSH. agentZ installs its server there and keeps it updated.

Agents keep running

A background server on each machine owns the agents, so quitting the app or losing the connection doesn't stop them.

Worktrees and pastures

Give a thread its own git worktree, or an instant copy-on-write copy of the project.

Real terminals

Terminals and split panes beside the agents, for the agent CLIs that run in one.

Free and open source, built on Zed's GPUI. github.com/ahrorbeksoft/agentZ
